# v0.8 upgrade — Identity & Persistence

This release replaces anonymous browser learner IDs and SQLite history with authenticated accounts and PostgreSQL.

## Important after replacing files

Your existing `backend/.env` is intentionally not replaced. Add these lines while keeping the Cloudflare values already present:

```env
DATABASE_URL=postgresql+psycopg://misconception:misconception@localhost:5432/misconception_mri
AUTO_CREATE_SCHEMA=1
ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
APP_BASE_URL=http://localhost:3000
SESSION_COOKIE_NAME=mri_session
SESSION_DAYS=14
SESSION_COOKIE_SECURE=0
EMAIL_MODE=console
EXPOSE_DEV_EMAIL_LINKS=1
```

Then run `docker compose up -d postgres`, reinstall backend requirements, restart backend/frontend, and create a fresh account. v0.7 anonymous SQLite history is not automatically migrated because v0.8 intentionally changes ownership from a browser-generated ID to a verified account.

For production, use Alembic and managed PostgreSQL instead of `AUTO_CREATE_SCHEMA=1`.
