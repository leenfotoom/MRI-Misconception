# Misconception MRI v0.3 — Product Upgrade

This version upgrades the hackathon prototype from a single demo screen into a fuller product experience while keeping the core diagnostic loop intact.

## Frontend upgrade

- Product-style global navigation: Home, Diagnostic Lab, Insights, System.
- Redesigned landing page with live mental-model preview and clear product positioning.
- Full bilingual English/Arabic UI with RTL direction switching.
- Product-style diagnostic workspace with session navigation and engine status.
- Visual mental-model graph, not only probability bars.
- Stronger active-learning panel explaining expected information gain.
- Stronger evidence/result experience with deterministic measurements and before/after belief shift.
- Local scan history stored in `localStorage`.
- Learning Insights dashboard generated from completed scans.
- Transparent System/Architecture page explaining the separation between LLM parsing, Bayesian inference, information gain, and deterministic physics.
- More polished SVG circuit with live current animation and measurement probes.

## Backend adjustment

- GPT-OSS summary is instructed to use the same language as the student's explanation.
- Existing Bayesian, information-gain, and deterministic physics behavior is preserved.
